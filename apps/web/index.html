Features

Built for clearing a pile, not admiring a dashboard.

Rules first, then you

Text is read from the PDF itself or, on a Mac, iPhone, or iPad, with Apple's on-device OCR for scans and photos. Rules extract the fields, and anything uncertain goes to review.

A table or a board

Work through a dense table with J K and A, or drag cards across Needs review, Ready, and Approved.

Answers you can audit

Ask about spend and get a total from a bound SQL query over reviewed records, with the query shown. No numbers made up by a language model.

Money stored as money

Amounts are integer minor units with a currency code. Currencies are totalled separately, never silently converted.

Exports your accountant takes

Canonical, QuickBooks-shaped, and Xero-shaped CSV, guarded against spreadsheet formula injection. You see where a file goes before it's written.

Reading in the background

Imports queue and are read one at a time. A crash or quit picks up where it left off, and anything still waiting can be cancelled.

Measured

Numbers from a real benchmark, not a demo.

The latest recorded run on the 100 receipt photos in the CORD v2 test set, with Apple Vision OCR and the rules on an Apple M2. The rules were tuned on a separate set of receipts. Every receipt still went to review, so nothing wrong was accepted without a person checking it.

Privacy

Nothing to upload, because nothing leaves.

Source files, extracted records, and query results stay in one folder on your computer, under your user account. Ledgerlens makes no network requests.

  • Files are admitted by their bytes, not their names, and capped at 25 MB.
  • PDF parsing and OCR run isolated and time-limited, so a hostile file can't hang the app.
  • Query values are bound parameters; query shape comes from a closed set.
  • Folder watching never follows links and only reads the one folder you chose.
  • Files are not encrypted at rest yet. Planned

Download

Try the preview.

Mac: download the .dmg for your chip (aarch64 for Apple silicon, x64 for Intel) and drag Ledgerlens to Applications. It isn't notarized yet, so macOS blocks the first launch: close the warning, then choose Open Anyway in System Settings › Privacy & Security.

Windows: run the -setup.exe. It isn't code-signed yet, so if SmartScreen appears, choose More info, then Run anyway. Linux: install the .deb or .rpm, or run the .AppImage. Android: open the .apk on your phone and allow installing from your browser or Files when Android asks.
